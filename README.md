# 4Lキャリアクエスト (4L Career Quest) - Web Prototype

「経験」を表すカードマスを巡り、偶発的な出来事（4L要素）を受け入れながら、獲得した経験を自分の強み（ポータブルスキル）へ意味づけ・変換し、自己決定目標を目指す自律型キャリアシミュレーションゲームのAstro Webアプリです。

## 🌟 主な特徴

- **RIASECキャラクター (6種)**: タクミ (R), サクラ (I), アオイ (A), カレン (S), ダイキ (E), リツコ (C) による得意スキル1.5倍補正・独自特権
- **3つの年代別ルール**: 20代（自己発見・2枚吸収）, 30代（選択と集中・3枚中2枚選択）, 40〜50代（効果2倍・2枚中1枚選択）
- **所属コース補正**: ベンチャーコース (スキルpt +1) vs 大手企業コース (学びドロー +1)
- **4Lパラメーター**: Labor (仕事), Learn (学び), Love (関係), Leisure (余暇) の人生充実度システム
- **ポータブルスキル**: 対人 (コミット), 思考 (ロジック), 実行 (ドライブ), 柔軟 (アザイル)
- **協力プロジェクト**: 蓄積したスキルを持ち寄って中間ゴールを共創達成

## 🛠️ 技術スタック

- **Framework**: Astro (v5)
- **UI Architecture**: React (v19) + Lucide Icons + Canvas Confetti
- **Styling**: Vanilla CSS (Modern Design System, Glassmorphism)
- **TypeScript**: Strict type safety

## 🚀 開発・起動手順

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# プロダクションビルド
npm run build
```
